=== funktionen | Funktionen | 20
Eine **Funktion** ist ein Stück Code mit einem Namen. Du schreibst es einmal und kannst es danach beliebig oft benutzen. Funktionen sind der wichtigste Baustein überhaupt: Jede Angular-App besteht zum grössten Teil aus Funktionen.

Du kennst schon welche: `console.log(...)`, `Math.round(...)`. Jetzt schreibst du eigene.

## Eine Funktion schreiben und aufrufen

```ts
function begruesse(name: string): string {
  return `Hallo ${name}!`;
}

const text = begruesse("Mia");
console.log(text);             // Hallo Mia!
console.log(begruesse("Noah")); // Hallo Noah!
```

Die erste Zeile hat fünf Teile:

1. `function` – das Schlüsselwort.
2. `begruesse` – der Name. Funktionen heissen meist wie eine Tätigkeit: `berechne...`, `zeige...`, `ist...`.
3. `(name: string)` – der **Parameter**: ein Wert, den die Funktion von aussen bekommt. Dahinter steht sein Typ.
4. `: string` nach der Klammer – der **Rückgabetyp**: Was für einen Wert liefert die Funktion zurück?
5. `{ ... }` – der Rumpf: der Code, der beim Aufruf läuft.

`return` gibt einen Wert zurück und beendet die Funktion sofort. Der Aufruf `begruesse("Mia")` wird sozusagen durch den zurückgegebenen Wert ersetzt.

> [!MERKE] Definieren ist nicht aufrufen
> Eine Funktion zu schreiben, führt sie noch nicht aus. Sie läuft erst, wenn du sie mit Namen und runden Klammern aufrufst: `begruesse("Mia")`.

## Mehrere Parameter

Parameter werden durch Kommas getrennt. Jeder bekommt seinen eigenen Typ:

```ts
function rechteckFlaeche(breite: number, hoehe: number): number {
  return breite * hoehe;
}

console.log(rechteckFlaeche(8, 5)); // 40
```

Beim Aufruf zählt die **Reihenfolge**: Der erste Wert landet im ersten Parameter, der zweite im zweiten.

## TypeScript prüft jeden Aufruf

Hier zeigt sich, warum die Typen so wertvoll sind. Alle diese Aufrufe sind in JavaScript erlaubt und führen zu Unsinn – TypeScript meldet sie sofort:

```ts error
function rechteckFlaeche(breite: number, hoehe: number): number {
  return breite * hoehe;
}

rechteckFlaeche(8);        // ein Argument fehlt
rechteckFlaeche("8", "5"); // Text statt Zahl
rechteckFlaeche(8, 5, 2);  // eines zu viel
```

## Funktionen ohne Rückgabewert

Manche Funktionen tun nur etwas, ohne ein Ergebnis zu liefern. Ihr Rückgabetyp heisst `void` («leer»):

```ts
function zeigeTrennlinie(): void {
  console.log("--------------------");
}

zeigeTrennlinie();
```

## Ausgeben oder zurückgeben?

Das verwechseln am Anfang fast alle:

- `console.log(wert)` **zeigt** einen Wert an. Das Programm kann danach nichts mehr damit tun.
- `return wert` **gibt** einen Wert an die aufrufende Stelle zurück. Dort kannst du weiterrechnen, ihn speichern oder ausgeben.

Meistens ist `return` das, was du willst. Eine Funktion, die ihr Ergebnis zurückgibt, kannst du überall einsetzen.

## Sichtbarkeit von Variablen

Variablen, die du **in** einer Funktion anlegst, existieren nur dort. Von aussen sind sie nicht sichtbar. Dasselbe gilt für alle geschweiften Klammern (`if`, `for`):

```ts error
function berechne(): number {
  const zwischenergebnis = 42;
  return zwischenergebnis * 2;
}

console.log(zwischenergebnis);
```

Das ist gewollt: So können sich Funktionen nicht gegenseitig in die Quere kommen.

=== pfeilfunktionen | Pfeilfunktionen und flexible Parameter | 15
Es gibt eine zweite, kürzere Schreibweise für Funktionen: die **Pfeilfunktion** (englisch «arrow function»). In Angular begegnet sie dir auf Schritt und Tritt.

## Von der Funktion zur Pfeilfunktion

```ts
// klassisch
function verdopple(zahl: number): number {
  return zahl * 2;
}

// als Pfeilfunktion
const verdopplePfeil = (zahl: number): number => {
  return zahl * 2;
};

// Pfeilfunktion in Kurzform
const verdoppleKurz = (zahl: number): number => zahl * 2;

console.log(verdopple(4), verdopplePfeil(4), verdoppleKurz(4));
```

Alle drei tun dasselbe. Bei der Pfeilfunktion fällt das Wort `function` weg, dafür steht zwischen Parametern und Rumpf ein Pfeil `=>`. Die Funktion wird in einer normalen `const`-Variable gespeichert.

Die **Kurzform** in der letzten Variante: Besteht der Rumpf nur aus einem einzigen `return`, darfst du die geschweiften Klammern und das Wort `return` weglassen. Was hinter dem Pfeil steht, wird automatisch zurückgegeben.

## Wozu zwei Schreibweisen?

Pfeilfunktionen sind praktisch, wenn man eine kleine Funktion **an eine andere Funktion übergibt**. Das klingt jetzt seltsam, wird aber in zwei Lektionen (bei den Array-Methoden) dein tägliches Brot:

```ts
const zahlen = [1, 2, 3];
const verdoppelt = zahlen.map((zahl) => zahl * 2);
console.log(verdoppelt); // [ 2, 4, 6 ]
```

Als Faustregel: Für eigenständige, benannte Funktionen nimmst du `function`. Für kleine Funktionen, die du direkt irgendwo übergibst, nimmst du den Pfeil.

## Optionale Parameter

Manchmal soll ein Parameter freiwillig sein. Dafür setzt du ein Fragezeichen hinter den Namen:

```ts
function begruesse(name: string, titel?: string): string {
  if (titel) {
    return `Guten Tag, ${titel} ${name}`;
  }
  return `Hallo ${name}`;
}

console.log(begruesse("Mia"));              // Hallo Mia
console.log(begruesse("Keller", "Frau"));   // Guten Tag, Frau Keller
```

Wird der Parameter weggelassen, hat er den besonderen Wert `undefined` («nicht definiert»). Mit `if (titel)` prüfst du, ob etwas übergeben wurde.

## Standardwerte

Oft ist es noch einfacher, einem Parameter einen **Standardwert** zu geben. Der gilt, wenn beim Aufruf nichts übergeben wird:

```ts
function potenz(basis: number, hochzahl: number = 2): number {
  return basis ** hochzahl;
}

console.log(potenz(5));    // 25 – hochzahl ist automatisch 2
console.log(potenz(2, 10)); // 1024
```

Optionale Parameter und Parameter mit Standardwert müssen immer **am Ende** stehen.

=== arrays | Arrays: Listen von Werten | 20
Ein **Array** ist eine geordnete Liste von Werten. Statt zwanzig einzelner Variablen für zwanzig Schülernamen hast du eine Variable mit einer Liste darin.

## Ein Array anlegen

```ts
const farben: string[] = ["rot", "grün", "blau"];
const punkte: number[] = [12, 7, 23, 5];
const leer: string[] = [];

console.log(farben, punkte, leer);
```

Die Werte stehen in **eckigen** Klammern, getrennt durch Kommas. Der Typ `string[]` bedeutet «Array von Strings», `number[]` «Array von Zahlen». TypeScript sorgt dafür, dass in einem `string[]` wirklich nur Strings landen.

Auf der Schweizer Tastatur tippst du `[` und `]` mit [[AltGr]] + [[ü]] und [[AltGr]] + [[¨]] (Mac: [[Option]] + [[5]] und [[Option]] + [[6]]).

## Auf Elemente zugreifen

Jedes Element hat eine Nummer, den **Index**. Gezählt wird – wie bei Strings – ab 0.

```ts
const farben = ["rot", "grün", "blau"];

console.log(farben[0]);      // "rot" – das erste Element
console.log(farben[2]);      // "blau" – das dritte Element
console.log(farben.length);  // 3 – Anzahl Elemente
console.log(farben[farben.length - 1]); // "blau" – das letzte Element

farben[1] = "gelb";          // ein Element ersetzen
console.log(farben);         // [ 'rot', 'gelb', 'blau' ]
```

Moment – `farben` ist doch `const`, warum darf man es ändern? `const` heisst nur: Die Variable zeigt immer auf **dasselbe Array**. Der Inhalt des Arrays darf sich ändern. Verboten wäre nur `farben = [...]`, also ein komplett neues Array zuzuweisen.

## Elemente hinzufügen und entfernen

```ts
const liste = ["Brot", "Milch"];

liste.push("Käse");        // hinten anfügen
console.log(liste);        // [ 'Brot', 'Milch', 'Käse' ]

const letztes = liste.pop(); // hinten entfernen (und zurückgeben)
console.log(letztes);      // "Käse"

console.log(liste.includes("Milch")); // true – ist das enthalten?
console.log(liste.indexOf("Milch"));  // 1 – an welcher Stelle?
```

TypeScript passt auf, was du hineinlegst:

```ts error
const punkte: number[] = [12, 7];
punkte.push("dreizehn");
```

## Ein Array durchgehen: for...of

Um mit **jedem** Element etwas zu tun, gibt es eine besonders bequeme Schleife:

```ts
const namen = ["Mia", "Noah", "Lena"];

for (const name of namen) {
  console.log(`Hallo ${name}!`);
}
```

Lies es so: «Für jeden `name` aus `namen` …». In jedem Durchlauf steckt das nächste Element in der Variable `name`. Du brauchst keinen Zähler und keinen Index und kannst dich nicht verzählen.

Die klassische `for`-Schleife mit Index brauchst du nur noch, wenn du die Position wirklich benötigst.

## Arrays und Funktionen

Arrays sind ganz normale Werte. Du kannst sie an Funktionen übergeben und zurückgeben:

```ts
function groesste(zahlen: number[]): number {
  let bisherGroesste = zahlen[0];
  for (const zahl of zahlen) {
    if (zahl > bisherGroesste) {
      bisherGroesste = zahl;
    }
  }
  return bisherGroesste;
}

console.log(groesste([4, 19, 7])); // 19
```

=== array-methoden | Array-Methoden: map, filter und Co. | 25
Arrays durchgehen, etwas herausfiltern, etwas umrechnen – das kommt so oft vor, dass es dafür fertige Methoden gibt. Sie ersetzen viele Schleifen und sind in Angular allgegenwärtig. Nimm dir für diese Lektion Zeit.

Allen gemeinsam ist: Du übergibst ihnen eine **kleine Funktion**, und die Methode ruft diese Funktion für jedes Element auf. Dafür sind Pfeilfunktionen ideal.

## map – jedes Element umwandeln

`map` macht aus einem Array ein **neues Array gleicher Länge**. Deine Funktion sagt, was aus jedem Element werden soll.

```ts
const preise = [10, 20, 30];
const mitMwst = preise.map((preis) => preis * 1.081);
console.log(mitMwst); // drei Preise, jeweils mit 8.1 % Zuschlag

const namen = ["mia", "noah"];
const gross = namen.map((name) => name.toUpperCase());
console.log(gross); // [ 'MIA', 'NOAH' ]
```

Den Typ von `preis` musst du nicht hinschreiben: TypeScript weiss, dass `preise` ein `number[]` ist, also ist jedes Element eine `number`.

## filter – nur manche Elemente behalten

`filter` liefert ein **neues Array mit den Elementen, für die deine Funktion `true` ergibt**.

```ts
const zahlen = [5, 12, 8, 21, 3];
const grosse = zahlen.filter((zahl) => zahl > 7);
console.log(grosse); // [ 12, 8, 21 ]
```

## find – das erste passende Element

`find` liefert **ein einzelnes Element**: das erste, für das deine Funktion `true` ergibt. Passt keines, kommt `undefined` zurück.

```ts
const namen = ["Mia", "Noah", "Nina"];
const mitN = namen.find((name) => name.startsWith("N"));
console.log(mitN); // "Noah"
```

## some und every – Fragen an das ganze Array

```ts
const noten = [5, 4.5, 3.5, 6];
console.log(noten.some((note) => note < 4));   // true – mindestens eine ungenügend?
console.log(noten.every((note) => note >= 3)); // true – alle mindestens 3?
```

## reduce – alles zu einem Wert zusammenfassen

`reduce` ist die anspruchsvollste Methode. Sie geht das Array durch und führt dabei einen **Zwischenstand** mit. Deine Funktion bekommt den Zwischenstand und das aktuelle Element und gibt den neuen Zwischenstand zurück. Die `0` am Ende ist der Startwert.

```ts
const zahlen = [3, 5, 10];
const summe = zahlen.reduce((zwischenstand, zahl) => zwischenstand + zahl, 0);
console.log(summe); // 18
```

Wenn dir das noch zu abstrakt ist: Eine `for...of`-Schleife tut dasselbe und ist völlig in Ordnung.

## Weitere nützliche Methoden

```ts
const namen = ["Noah", "Mia", "Lena"];

console.log(namen.join(", "));        // "Noah, Mia, Lena" – zu einem Text verbinden
console.log(namen.slice(0, 2));       // [ 'Noah', 'Mia' ] – Ausschnitt kopieren
console.log([...namen].sort());       // [ 'Lena', 'Mia', 'Noah' ] – sortierte Kopie
console.log("a,b,c".split(","));      // [ 'a', 'b', 'c' ] – Text in Array zerlegen
```

`sort()` verändert das ursprüngliche Array. Mit `[...namen]` machst du vorher eine Kopie – was die drei Punkte bedeuten, lernst du in Teil 3.

> [!WARN] Zahlen sortieren
> `sort()` ohne Angabe sortiert wie im Wörterbuch – auch Zahlen. Aus `[10, 9, 1]` wird `[1, 10, 9]`. Für Zahlen übergibst du eine Vergleichsfunktion: `zahlen.sort((a, b) => a - b)`.

## Methoden verketten

Weil `map` und `filter` wieder Arrays liefern, kannst du sie hintereinanderhängen:

```ts
const punkte = [45, 82, 67, 91, 38];

const ergebnis = punkte
  .filter((p) => p >= 50)
  .map((p) => `${p} Punkte`);

console.log(ergebnis); // [ '82 Punkte', '67 Punkte', '91 Punkte' ]
```

> [!MERKE] Welche Methode wofür?
> - Gleich viele Elemente, aber verändert → `map`
> - Weniger Elemente, unverändert → `filter`
> - Genau ein Element → `find`
> - Eine Ja/Nein-Antwort → `some` / `every`
> - Ein einzelner Gesamtwert → `reduce`

--- code kette-durchschnitt | Alles zusammen: Notendurchschnitt
Schreibe eine Funktion `durchschnitt`, die ein Array von Noten bekommt und den Durchschnitt zurückgibt.

- Ungültige Noten (kleiner als 1 oder grösser als 6) sollen **ignoriert** werden.

@starter
// Schreibe hier die Funktion durchschnitt

@solution
// Schreibe hier die Funktion durchschnitt
function durchschnitt(noten: number[]): number {
  const gueltige = noten.filter((note) => note >= 1 && note <= 6);
  if (gueltige.length === 0) {
    return 0;
  }
  const summe = gueltige.reduce((zwischenstand, note) => zwischenstand + note, 0);
  return summe / gueltige.length;
}

console.log(durchschnitt([4, 5, 99, 6]));
@tests
fn durchschnitt(number[]): number
run durchschnitt([4, 5, 99, 6]) === 5 :: `durchschnitt([4, 5, 99, 6])` ergibt `5`
run durchschnitt([6, 6]) === 6 && durchschnitt([4, 5]) === 4.5 :: Normale Noten werden richtig gemittelt
run durchschnitt([0, 7, -3]) === 0 :: Nur ungültige Noten ergeben `0`
run durchschnitt([]) === 0 :: Ein leeres Array ergibt `0` ?? Teilst du durch die Anzahl, ohne zu prüfen, ob sie 0 ist? `0 / 0` ergibt `NaN`.
@hints
- Schritt 1: die gültigen Noten herausfiltern: `noten.filter((note) => note >= 1 && note <= 6)`
- Schritt 2: Wenn das gefilterte Array leer ist (`length === 0`), sofort `return 0;`
- Schritt 3: Summe bilden (mit `reduce` oder einer `for...of`-Schleife) und durch die Anzahl der gültigen Noten teilen.
@after

=== objekte | Objekte: zusammengehörige Daten | 20
Ein Array ist eine Liste gleichartiger Dinge. Oft gehören aber **verschiedene** Angaben zusammen: Ein Buch hat einen Titel, eine Seitenzahl und einen Autor. Dafür gibt es **Objekte**.

## Ein Objekt anlegen

```ts
const buch = {
  titel: "Momo",
  autor: "Michael Ende",
  seiten: 304,
  gelesen: true,
};

console.log(buch.titel);  // "Momo"
console.log(buch.seiten); // 304
```

Ein Objekt steht in **geschweiften** Klammern und besteht aus **Eigenschaften** (englisch «properties»). Jede Eigenschaft hat einen Namen und einen Wert, getrennt durch einen Doppelpunkt. Zwischen den Eigenschaften stehen Kommas.

Auf eine Eigenschaft greifst du mit einem **Punkt** zu: `buch.titel`. Diese Schreibweise kennst du schon von `wort.length` und `console.log` – auch das sind Objekte mit Eigenschaften.

Auf der Schweizer Tastatur tippst du `{` und `}` mit [[AltGr]] + [[ä]] und [[AltGr]] + [[$]] (Mac: [[Option]] + [[8]] und [[Option]] + [[9]]).

## Eigenschaften ändern

```ts
const buch = { titel: "Momo", seiten: 304, gelesen: false };

buch.gelesen = true;
buch.seiten += 10;
console.log(buch);
```

## TypeScript kennt die Form deines Objekts

TypeScript merkt sich, welche Eigenschaften ein Objekt hat und welche Typen sie haben. Tippfehler und falsche Werte fallen sofort auf:

```ts error
const buch = { titel: "Momo", seiten: 304 };

console.log(buch.title);  // Tippfehler: heisst "titel"
buch.seiten = "viele";    // seiten ist eine Zahl
```

In JavaScript würde `buch.title` einfach `undefined` ergeben – ohne Warnung. Solche Fehler sucht man manchmal stundenlang. In TypeScript siehst du sie sofort.

> [!VSCODE] Vorschläge beim Tippen
> Tippe in VS Code `buch.` – also den Namen und einen Punkt. Sofort erscheint eine Liste aller Eigenschaften. Mit den Pfeiltasten und [[Enter]] oder [[Tab]] wählst du aus. Das heisst **IntelliSense** und funktioniert nur so gut, weil TypeScript die Typen kennt.

## Den Typ eines Objekts hinschreiben

Auch für Objekte kannst du den Typ angeben. Er sieht fast aus wie das Objekt selbst, nur stehen Typen statt Werte da, und die Eigenschaften werden durch **Strichpunkte** getrennt:

```ts
const spieler: { name: string; punkte: number } = {
  name: "Alex",
  punkte: 0,
};
console.log(spieler);
```

Besonders wichtig ist das bei Funktionsparametern:

```ts
function beschreibe(buch: { titel: string; seiten: number }): string {
  return `${buch.titel} hat ${buch.seiten} Seiten.`;
}

console.log(beschreibe({ titel: "Momo", seiten: 304 }));
```

Das wird schnell lang und unübersichtlich. Im nächsten Teil lernst du, solchen Typen mit `interface` einen Namen zu geben – dann schreibst du nur noch `buch: Buch`.

## Objekte in Arrays

Richtig nützlich wird es, wenn du beides kombinierst. Ein Array von Objekten ist die häufigste Datenform in jeder Web-App: eine Liste von Produkten, Nachrichten, Aufgaben …

```ts
const buecher = [
  { titel: "Momo", seiten: 304 },
  { titel: "Krabat", seiten: 256 },
  { titel: "Tintenherz", seiten: 576 },
];

const dicke = buecher.filter((buch) => buch.seiten > 300);
const titel = dicke.map((buch) => buch.titel);

console.log(titel); // [ 'Momo', 'Tintenherz' ]
```

Hier arbeiten die Array-Methoden aus der letzten Lektion mit Objekten zusammen. Genau so sieht später der Code in deinen Angular-Apps aus.
